# Amazon Sales Data Analysis Dashboard (Power BI)

## 📌 Project Overview
This project focuses on analyzing Amazon sales data to understand sales performance, product trends, customer demand, and revenue distribution. The goal is to provide actionable business insights through an interactive Power BI dashboard that supports data-driven decision-making.

---

## 🛠 Tools & Technologies Used
- Power BI
- Microsoft Excel
- CSV Dataset
- Data Cleaning & Transformation
- Data Modeling
- DAX Measures

---

## 📂 Datasets Used
- **Amazon Sale Report - YT.xlsx** – Cleaned and structured sales data  
- **amazon-fashion - YT.csv** – Raw transactional sales dataset  

The datasets include information such as order details, product categories, sales amount, quantity, and dates.

---

## 📊 Key Analysis & Insights
- Identified total sales, total orders, and revenue trends
- Analyzed category-wise and product-wise sales performance
- Evaluated monthly and yearly sales trends
- Identified high-performing and low-performing product categories
- Analyzed customer purchase patterns based on sales data

---

## 📈 Dashboard Features
- KPI cards for Total Sales, Orders, and Revenue
- Category-wise and product-wise sales analysis
- Time-based analysis using interactive slicers
- Dynamic filters for better data exploration
- Clean and user-friendly dashboard design
